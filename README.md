# Celestia · 天使秘境塔罗

这是一个纯静态网站，无需安装依赖或配置服务器。

## 本地预览
双击 `index.html` 即可在浏览器中打开。

## 发布到 GitHub Pages
1. 登录 GitHub，打开 https://github.com/new
2. Repository name 填 `celestia-tarot`。
3. 选择 Public，点击 Create repository。
4. 在新仓库页面点 `uploading an existing file`（或 Add file → Upload files）。
5. 把 `index.html` 拖进去；也可以把 README.md 一起拖进去。
6. 点击 Commit changes。
7. 打开仓库 Settings → Pages。
8. 在 Build and deployment 下，Source 选 `Deploy from a branch`。
9. Branch 选 `main`，文件夹选 `/ (root)`，点击 Save。
10. 等待页面显示已发布网址，通常是 `https://你的GitHub用户名.github.io/celestia-tarot/`。

注意：首次部署可能需要几分钟。GitHub Pages 的地址以 Settings → Pages 显示为准。
